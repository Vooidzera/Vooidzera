# Como eu trabalho

Não gosto de escolher tecnologia antes de entender o problema.

Meu foco é construir soluções que sejam úteis, compreensíveis e sustentáveis.

Quando uma ferramenta de automação resolve o problema, uso automação.

Quando o sistema exige controle maior, entro no desenvolvimento tradicional.

Quando existe uma aplicação real para inteligência artificial, integro IA ao sistema.

**A tecnologia é o meio. O sistema funcionando é o objetivo.**
