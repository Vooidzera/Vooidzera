## Sobre mim

Sou desenvolvedor de software com foco em **desenvolvimento, automação e inteligência artificial**.

Meu trabalho envolve construir sistemas que conectam aplicações, APIs, bancos de dados, workflows e modelos de linguagem para transformar processos em soluções funcionais.

Tenho experiência tanto com desenvolvimento tradicional quanto com ferramentas de automação e IA, utilizando cada abordagem de acordo com o problema.

> **Software first. Automation when it makes sense. AI when it adds value.**

# Como eu trabalho

Não gosto de escolher tecnologia antes de entender o problema.

Meu foco é construir soluções que sejam úteis, compreensíveis e sustentáveis.

Quando uma ferramenta de automação resolve o problema, uso automação.

Quando o sistema exige maior controle, entro no desenvolvimento tradicional.

Quando existe uma aplicação real para inteligência artificial, integro IA ao sistema.

**A tecnologia é o meio. O sistema funcionando é o objetivo.**
